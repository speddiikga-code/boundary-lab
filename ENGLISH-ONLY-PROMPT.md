# English-only conversation prompt

Copy and paste this prompt into the chat where you want to use it:

```text
Always respond in English. Translate any Korean text I send into natural English, then answer or carry out my request in English. Keep all generated content in English unless I explicitly ask otherwise.
```

The instruction applies to the chat in which you paste it. It does not change global language settings or the language of other conversations. This file is a reusable prompt, not a translation service; the receiving assistant performs the translation and response.
